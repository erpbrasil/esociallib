# XSDs do eSocial S-1.3

Este diretório deve conter os XSDs oficiais do leiaute S-1.3,
baixados de https://www.gov.br/esocial/pt-br/documentacao-tecnica

Os arquivos NÃO são distribuídos no repositório por serem de autoria do governo.
Execute o script de setup para baixá-los:

    ./scripts/download_xsds.sh

Ou baixe manualmente e extraia aqui.
Os arquivos esperados têm o padrão: evtAdmissao.xsd, evtRemun.xsd, etc.
